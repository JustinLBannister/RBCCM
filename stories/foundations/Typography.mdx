# Typography

Two families. Headings use RBC Display, a serif; everything else uses Roboto. The components name them as `RBCDisplay, 'RBC Display', Georgia, Times, serif` and `Roboto, Arial, sans-serif`.

RBC Display is loaded by the live site, not by this page. If it is not installed on your computer the samples below fall back to Georgia.

## Headings: RBC Display

<Typeset
  fontFamily={'RBCDisplay, "RBC Display", Georgia, Times, serif'}
